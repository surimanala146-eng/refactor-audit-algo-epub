TRAVAIL DEMANDÉ
---------------
1. COMMANDE ONE-SHOT (priorité absolue)
   Une seule commande qui prend un dossier de .txt et produit le résultat :
       python -m orchestration <dossier_livres> <dossier_sortie>
   Sortie : manifest.json + fiches .md dans <dossier_sortie>.
   Aucune question posée, aucune config obligatoire, aucune attente
   d'entrée clavier. Les seuils de configs/pipeline.yaml servent de défauts.

2. WEBAPP UNE SEULE PAGE (si l'interface web est conservée)
   Une seule vue qui enchaîne visuellement :
   - zone de dépôt/sélection du dossier de livres,
   - UN bouton « Lancer »,
   - progression en direct (les événements SSE existent déjà),
   - résultats (fiches + manifest + export.zip) affichés
     automatiquement à la fin, sans changer d'onglet.
   Retirer ou rabattre les onglets devenus inutiles.

3. ZÉRO INTERACTION HUMAINE — invariant
   Nulle part le pipeline ne doit attendre une décision, une validation
   ou une saisie. En cas d'ambiguïté : règle automatique documentée,
   jamais une pause « en attente d'humain ».

4. SIMPLICITÉ DE SORTIE
   Le résultat visible = les fiches + le manifest, ouvrables
   directement. Un zip téléchargeable suffit pour l'export.

CRITÈRE D'ACCEPTATION (test que le client fera)
