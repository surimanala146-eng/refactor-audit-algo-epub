5. DETTE TECHNIQUE, DÉPENDANCES & SÉCURITÉ
--------------------------------------------------------------------------------
A. TODO / FIXME :
   - Aucun marqueur TODO ou FIXME dans le code source Python applicatif.
   - Code propre et documenté avec typage moderne (Python 3.11+ / __future__.annotations).

B. Dépendances non utilisées (requirements.txt / pyproject.toml) :
   - "numpy>=1.26" : Déclaré dans requirements.txt et pyproject.toml, mais jamais
     importé ni utilisé dans l'arborescence Python du projet.
   - "ebooklib" et "beautifulsoup4" : Utilisés dans ingestion/loader.py (conversion EPUB).
   - "pymupdf" (fitz) : Utilisé dans ingestion/loader.py (extraction PDF).
   - "pyyaml" : Utilisé dans orchestration/pipeline.py (lecture de configs/pipeline.yaml).

C. Rôle réel de package.json & node_modules :
   - package.json définit devDependencies : "@playwright/test": "^1.55.1", "puppeteer": "^25.12.0".
   - tests/browser-ui.spec.js et tests/puppeteer-ui.mjs sont des scripts de tests E2E.
   - "scripts": {"test": "echo \"Error: no test specified\" && exit 1"}.
   - L'interface réelle est un unique fichier HTML/JS statique (webapp/static/index.html)
     servi directement par FastAPI. Le tooling Node.js ne participe à aucun build
     et sert uniquement à d'éventuels tests navigateurs headless.

D. Analyse du module MongoDB (retrieval/mongo_store.py & tests/test_mongo.py) :
   - retrieval/mongo_store.py fournit MongoVectorStore (stockage d'embeddings).
   - Il n'est activé QUE si provider="mongodb" dans la configuration (webapp/providers.py:27).
   - Par défaut, provider="local" (DeterministicHashEmbedding). MongoDB n'est donc
     pas sollicité en utilisation normale.
   - Fragilité dans tests/test_mongo.py : l'importation directe de mongomock à la ligne 7
     provoque un échec immédiat de pytest sous l'environnement système sans venv.

E. Fichiers obsolètes ou orphelins :
   - "back end final.txt" et "front end final.txt" : documents de travail statiques
     non synchronisés avec l'état réel du code (notamment sur l'arbitrage humain).
   - "graphify-out/" : artefacts d'indexation de graphe tiers présents à la racine.
   - "matrice_v2_console.egg-info/" : résidu de build local.
   - "workspace/" : contient cache.sqlite (80 Ko), sources.json et d'anciens runs
     (workspace/runs/*). Ignoré par .gitignore mais présent sur disque.

F. Points de sécurité (Anti-traversal & Upload) :
   - Racines autorisées (webapp/settings.py) :
     Par défaut, allowed_roots inclut (Path.home() / "Downloads", Path("./workspace/uploads")).
     Dans un environnement utilisateur où ~/Downloads héberge des répertoires sensibles
     (ex. frontière de production ~/Downloads/Newfo/), la fonction scan_folder
     (webapp/sources.py) permet un scan récursif (rglob) de tout le dossier Downloads.
   - Upload de fichiers (webapp/server.py) :
     L'endpoint POST /api/sources/upload effectue "data = await f.read()" avant de vérifier
     la taille maximale ("len(data) > limit"), ce qui charge la totalité du payload
     en mémoire RAM avant rejet éventuel (vulnérabilité DoS par épuisement mémoire).
